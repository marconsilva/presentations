Radius: The Open-Source Platform for Cloud-Native Application Development

Radius Platform Engineering Cloud-Native Kubernetes Open Source DevOps

Marco Antonio Silva · Senior Global Black Belt — Microsoft

Cloud-native development shouldn't require a PhD in Kubernetes, Terraform, and cloud provider specifics. Radius is Microsoft's open-source platform that provides a unified application model across clouds — letting developers define what their app needs while platform engineers define how those needs are fulfilled. This session deep-dives into Radius: its architecture, the application model, recipes, environments, and how it integrates with existing tools.
