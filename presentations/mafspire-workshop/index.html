MAFSpire: Building Production AI Agents with Microsoft Agent Framework & .NET Aspire

Workshop MAF .NET Aspire Multi-Agent Production

A full-day hands-on workshop that combines Microsoft Agent Framework (MAF) for building intelligent agents and .NET Aspire for running them in production. Morning session: design and build agents with MAF — roles, capabilities, tools, communication channels, and orchestration patterns. Afternoon session: deploy and operate with Aspire — service discovery, health checks, distributed tracing, and scaling strategies for multi-agent systems.
