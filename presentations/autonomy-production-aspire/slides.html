Custom Agent Health Checks

public class AgentHealthCheck : IHealthCheck
{
  public async Task<HealthCheckResult> CheckHealthAsync(
    HealthCheckContext context, CancellationToken ct)
  {
    var lastResponse = await _agent.GetLastResponseTime();
    var queueDepth = _agent.GetPendingTasks();

    if (lastResponse > TimeSpan.FromSeconds(30))
      return HealthCheckResult.Degraded("Slow");

    return HealthCheckResult.Healthy();
  }
}

Graceful Shutdown Pattern

  • Drain in-flight requests (finish current reasoning)
  • Persist agent state to durable store
  • Notify orchestrator of departure
  • Allow replacement agent to resume
Never kill an agent mid-reasoning: you lose context and may corrupt shared state.

Circuit Breakers for AI Services

Resilience when the LLM does not respond

AI Services Are Unreliable

  • Rate limits hit without warning (429s)
  • Latency spikes from 200ms to 30 seconds
  • Model endpoints go down for maintenance
  • Token limits cause silent truncation
Circuit breakers prevent one slow LLM from taking down your entire agent fleet.

Circuit Breaker States

Resilience with Polly + Aspire

builder.Services.AddHttpClient("llm-service")
  .AddResilienceHandler("ai-pipeline", pipeline =>
  {
    pipeline.AddCircuitBreaker(new CircuitBreakerStrategyOptions
    {
      FailureRatio = 0.3,
      SamplingDuration = TimeSpan.FromSeconds(30),
      BreakDuration = TimeSpan.FromSeconds(15)
    });
    pipeline.AddRetry(new RetryStrategyOptions
    {
      MaxRetryAttempts = 3,
      BackoffType = DelayBackoffType.Exponential
    });
  });

Lessons from Production

  • Start with 2 agents, not 10: complexity grows exponentially
  • Define clear agent boundaries (single responsibility)
  • Chaos-test your agents: inject failures early
  • Track cost per agent per task: LLM spend adds up fast
  • Never let agents modify production state without confirmation

Key Takeaways

1. Aspire = Agent Platform

Service discovery, health, telemetry: built for this

2. Observability First

If you cannot see it, you cannot fix it at 3 AM

3. Resilience by Design

4. Start Small, Scale Smart

Prove reliability before adding agents
