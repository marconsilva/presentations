The problem with "vibe-coding"

❌ Vibe-Coding

  • Prompt → code → hope it works
  • No verifiable correctness criteria
  • Hallucinations go undetected
  • Regression risk at scale

✅ Spec-Driven

  • Spec → code → validate against spec
  • Machine-readable contracts
  • Hallucinations caught by validation
  • Safe, incremental, verifiable
Spec-Driven Development

What is a Spec?

A structured, machine-readable description of what the code should do — separate from how it does it.

📋 Behavior Contracts

Input/output mappings, business rules, invariants

🔗 API Schemas

Endpoints, types, validation rules, error codes

🏗️ Architecture Specs

Component boundaries, dependencies, data flows

Specs reduce hallucinations

The spec is the oracle. If the output doesn't match, the LLM tries again.

Two complementary strategies to verify migration quality at scale.

  • Semantic equivalence checking

📏 Automated Metrics

Layer 2

Spec compliance — does it match the contract?

Layer 3

LLM-as-judge — is the behavior preserved?

Layer 4

Human review — final sign-off on critical paths

Lessons Learned

What worked and what we can do better

What worked

Where agentic modernization shines

  • Spec-first approach eliminated hallucination drift — the spec is the oracle, not the prompt
  • RAG grounding was essential — agents without codebase context produce generic, wrong code
  • Multi-layer validation caught 95%+ of issues before human review
  • Service-by-service decomposition kept each agent task within context limits
  • Automated evaluation enabled CI/CD for migrations — merge only when all gates pass
Retrospective

What we can do better

  • Invest more upfront in spec quality — garbage specs → garbage migrations
  • Build domain expert review into the spec generation phase, not just the code review phase
  • Start with simpler services to build trust and calibrate evaluation thresholds
  • Implement incremental migration with feature flags — not big-bang cutover
  • Track LLM cost per service from day one for realistic budgeting
