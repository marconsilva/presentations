Autonomy Unleashed: Multi-Agent Systems from MAF Orchestration to Squads

Conference Session · 45–60 min · Marco Antonio Silva, Senior Global Black Belt — Microsoft

AI Multi-Agent MAF Squads Orchestration

Single agents are powerful. But the real breakthrough comes when agents collaborate. In this session, we navigate from structured orchestration with Microsoft Agent Framework (MAF) to the Squads paradigm: composable, squad-based workflows where specialized agents tackle complex tasks together.
