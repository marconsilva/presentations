Agentic Modernization: Transforming Legacy Applications with GitHub Copilot CLI

Speaker Marco Antonio Silva, Senior Global Black Belt — Microsoft
Focus Modernizing legacy .NET estates with agentic analysis, planning, and execution
GitHub Copilot Modernization Legacy .NET CLI Enterprise

Every organization has legacy apps — and most modernization projects fail because teams cannot keep up with analysis, planning, and execution at scale. GitHub Copilot CLI turns modernization on its head: scanning legacy code, generating migration proposals, and executing refactoring steps autonomously. This session draws on real enterprise programs modernizing 150+ applications at a European bank.
