Agentic Modernization Lab: Hands-On Legacy Transformation with GitHub Copilot

Workshop GitHub Copilot Modernization .NET Lab

Hands-on lab where participants modernize a legacy .NET Framework application using Copilot CLI agent mode: codebase analysis, dependency mapping, migration strategy, automated refactoring, test generation, validation.

What You'll Do

  • Map dependencies, hotspots, and migration risks before touching code
  • Generate a phased strategy for refactoring, testing, and validation
  • Use Copilot to accelerate upgrades while keeping human review in the loop
